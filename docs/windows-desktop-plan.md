# CineSleuth Windows 桌面端接入方案

状态：开发设计，尚未实现或部署。依据 2026-09-08 的产品要求及本地代码核对。

实施进展：同日按用户缩减范围，已完成并部署第一阶段的桌面登录、视频／链接输入与云端模型分析。Agent 整理、分镜首帧和最终报告归档暂不实施。实际交付以 `../desktop/README.md` 为准，下文保留为原始完整规划。

## 一期范围

Windows 安装版包含 Lab 浏览器登录、本地视频及链接导入、分析进度、分镜结果、历史记录、报告整理、首帧提取及导出。继续保留 5 分钟视频上限；macOS 后续扩展。

任务属于当前 Lab 用户，产品来源继续为 `cine-sleuth`，独立记录入口 `desktop`。模型服务凭据仅由 Lab 后端使用。个人 API Key 与桌面设备授权相互独立。

## 现有接入点

| 代码 | 已有行为 | 桌面端需要的变化 |
| --- | --- | --- |
| `apps/web/app/skill-auth/page.tsx`（Lab 仓库） | 复用登录表单，经本机 HTTP 回调传递用户 API Key | 新增独立桌面授权页，复用正式登录页面；不复用 API Key 交换行为 |
| `apps/api/src/auth/skill-auth.controller.ts` | Skill 授权、身份读取及会话退出 | 新增桌面授权、交换、刷新及设备撤销接口 |
| `apps/api/src/auth/auth.service.ts` | 网页会话和个人 API Key 鉴权 | 增加独立桌面设备凭据鉴权，不给桌面凭据管理后台权限 |
| `apps/api/src/cine-sleuth/cine-sleuth.controller.ts` | 创建任务、分析、进度及结果读取、报告归档 | 接受桌面凭据，增加用户历史分页接口 |
| `apps/api/src/cine-sleuth/cine-sleuth.service.ts` | 固定产品来源、原视频保存、云端结果保存；完成与报告归档分离 | 保持完成规则，增加入口及设备审计信息、统一权益检查 |

现有 CineSleuth 插件由宿主 Agent 整理最终报告。独立桌面端没有这个宿主，不能只套一个界面就宣称具备同等报告能力。当前核对的 CineSleuth 服务代码中未见订阅或积分检查；上线前仍需核对全局网关并完成统一接入。

## 浏览器登录

1. 桌面主进程生成随机 `state` 和 PKCE verifier，只保留在本次登录事务中。
2. 系统浏览器打开正式 Lab 域名的桌面授权入口，携带 client ID、固定回调地址、state 和 S256 challenge。未登录时进入现有 Lab 登录页，成功后回到授权流程。
3. 后端校验已登记的客户端和精确回调地址，绑定当前网页用户及 PKCE challenge，产生短效一次性授权码。已有登录及授权可直接继续；首次授权展示应用及设备信息。
4. 浏览器通过已注册协议回到桌面端，例如 `cn.com.lycheeai.cinesleuth:/oauth/callback?code=...&state=...`。最终协议名需在安装包与服务端一致登记。
5. 主进程验证完整回调结构、state 和待处理事务，使用授权码及 verifier 经 HTTPS 换取设备 access token 和 refresh token。长期凭据不进入 URL。
6. Windows 安装包注册协议；主进程处理冷启动、已运行时的第二实例通知及重复回调。授权超时、取消或应用重启后丢失 verifier 时重新登录。

建议授权码有效期 90 秒、access token 10 分钟、refresh token 最长 30 天；这些是待配置的产品参数，不是现有能力。桌面应用是公开客户端，不嵌入 client secret。

服务端只保存凭据摘要；授权码须在数据库事务内原子消费并绑定 client、redirect URI 和 PKCE。刷新令牌轮换，记录令牌族并检测重复使用；客户端串行刷新，避免并发请求互相撤销。交换响应设为 no-store，日志脱敏。

refresh token 在主进程用 Windows 系统加密能力保护，access token 尽量只在内存保存；不放入页面 localStorage。渲染进程通过有限 IPC 操作任务，不取得长期凭据。加密存储不可用时不降级为明文保存。

## 拟新增接口与数据

以下路径是设计提案，尚未存在。

| 接口 | 用途及约束 |
| --- | --- |
| `GET /desktop-authorize` | Lab 正式域名下的浏览器授权页面 |
| `POST /api/desktop-auth/authorize` | 网页会话及 CSRF/来源校验后签发授权码 |
| `POST /api/desktop-auth/token` | 授权码交换，或 refresh token 轮换；不依赖浏览器 Cookie |
| `GET /api/desktop-auth/me` | 返回桌面用户及当前设备信息 |
| `POST /api/desktop-auth/logout` | 撤销当前设备令牌族及访问凭据 |
| `GET /api/account/desktop-devices` | 已登录 Lab 用户查看自己的设备授权 |
| `DELETE /api/account/desktop-devices/:id` | 按所有权撤销指定设备，不修改 API Key 或其他设备 |
| `GET /api/cine-sleuth/jobs` | 当前用户历史分页，支持入口筛选，不接受客户端指定用户身份 |

建议新增 `desktop_authorization_codes`、`desktop_devices`、`desktop_refresh_tokens` 和 `desktop_access_tokens`，包含有效期、撤销时间、关联用户及设备。设备标签用于展示，不能作为身份凭据。每次桌面鉴权检查设备撤销及用户状态，使远程退出及时生效。离线退出立即清除本机凭据，但必须明确提示尚未完成服务端撤销，可在 Lab 设备列表撤销。

任务增加独立 `entry_point` 字段及可选 `desktop_device_id`。入口由服务端根据已认证客户端设置，不能信任请求正文的任意产品来源。旧记录不能仅凭 API Key 判断来自哪一种宿主，迁移时保留未知值，不错误回填 desktop。

## 任务及报告

桌面端负责导入、媒体探测、切片、上传、恢复进度、首帧提取、预览及导出。Lab 负责用户身份、任务所有权、模型调用、原视频和云端结果保存，以及权益和计费。

分别记录和展示三种状态：

- 云端分析：排队、处理中、完成、失败。
- 本地报告：未整理、整理中、可导出、失败。
- 最终报告归档：未归档、归档中、已归档、失败。

云端模型结果完整保存后即完成分析；整理、导出或归档失败都不回退云端任务状态。用户通过“整理最终报告”“提取分镜首帧”“导出”“归档到 Lab”执行后续操作。首帧按最终语义分镜时间提取，不把技术切片当分镜。导出 HTML 单文件及 Markdown 加图片目录，沿用现有交付形式。

建议为独立桌面端增加受 Lab 鉴权和额度控制的报告整理能力：客户端明确发起，Lab 网关代理推理，客户端组织流程并保存报告。报告整理使用独立执行状态、版本和幂等请求，不覆盖原始模型证据；另行归档才写入最终报告存储。具体 Agent 运行时、模型和计费规则仍需选定，不能把简单拼接的模型输出标为完整 Agent 报告。

历史记录以 Lab 用户任务为准，本地保存缓存、报告版本及导出路径。换设备仍能看到云端任务；未归档的本地报告不会自动出现在另一设备。账号切换隔离缓存。链接导入失败时保留错误原因并提供本地文件入口。

## 权益与交付顺序

订阅、积分和配额由服务端在创建任务、实际模型执行及报告整理时统一检查。预占、结算、释放及重试须按任务和片段幂等，不能因重试重复扣费。客户端展示服务端返回的价格、余额和不足原因；商业规则未配置时不能自行推定免费或自行扣减。

1. 完成设备授权数据迁移、交换刷新及撤销测试；接入正式 Lab 登录与授权页面。
2. 为现有 CineSleuth 接口接入桌面身份、来源标记、历史分页和统一权益校验；核对管理后台的入口展示。
3. 实现 Electron 主进程、隔离的渲染界面及 Windows 协议回调，串通导入到云端结果的流程。
4. 接入报告执行能力、分镜首帧、导出和可选归档，验证重启恢复及账号隔离。
5. 生成 Windows 安装包，在干净 Windows 环境验证安装、协议注册、登录、升级及卸载。正式分发前配置代码签名。

## 验收

- 未登录及已登录浏览器均能授权回到客户端；错误 state、PKCE、回调地址、过期码和重复交换均被拒绝。
- 刷新可恢复正常调用；退出某设备后该设备不能访问或刷新，个人 API Key 和另一设备仍可使用。
- 不能跨用户读写任务、结果或设备；伪造 desktop 标记不能改变服务端权益判断。
- 管理后台可查看归属于 CineSleuth 的桌面任务、原片和云端模型结果。
- 网络中断和重启恢复不会重复创建任务或重复计费；任务完成不依赖报告归档。
- 无宿主 Agent 的干净 Windows 机器能够完成最终报告流程；如尚未接入，界面明确标识未支持，不冒充完整 MVP。
- 安装包、本机存储、日志、回调 URL、导出报告均不包含模型服务商密钥或明文长期桌面凭据。
