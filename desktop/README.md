## 使用

1. 运行 [Windows x64 2.0.7 安装包](https://prod-lab-1321001571.cos.ap-guangzhou.myqcloud.com/releases/cine-sleuth/windows/x64/CineSleuth-2.0.7-Windows-x64-Setup.exe) 安装。
2. 点击“登录 LycheeAILab”，在系统浏览器登录并授权，返回桌面端。
3. 选择最长 5 分钟的本地视频，或粘贴有权使用的抖音、Bilibili、YouTube 单条视频链接。确认片源授权及云端分析后开始。
4. 查看本机进度及模型结果。失败或重启后点击“继续”，已完成的云端片段会跳过。暂停本地流程不会取消已经提交到 Lab 的模型请求。
5. “分析历史”读取当前 Lab 账号的 CineSleuth 任务；“导出 JSON”保存原始模型结果。

2026-09-08，配套 Lab `0.4.6-prod`（`d6ec6ca`）已部署正式环境，可使用正式站点登录；此次仅更新 Web，不改 API、数据库或登录凭据。

## 构建

构建机需要 Node.js、npm、Python 和网络；安装包内含独立媒体运行环境，用户无需安装 Python 或 FFmpeg。

```powershell
cd desktop
npm install
npm run runtime
npm test
node tests/media-smoke.cjs
npm run dist
```

Electron 的 Node 下载器在某些网络中不可用时，可运行 `scripts/install-electron.ps1`。它会以 npm 包内置 SHA-256 校验镜像文件。FFmpeg 构建脚本从 Gyan 获取当前 release essentials 并验证发布方校验和，保存版本及许可；正式发布应固定归档和校验和以保证重建一致性。

开发启动：`npm start`。本地 Lab 联调可在未打包开发模式设置 `CINESLEUTH_LAB_URL=http://127.0.0.1:3000`，对应后端设置相同的 `LAB_PUBLIC_ORIGIN`。打包版本拒绝将 API 地址改为其他域名或本地地址。

界面验证脚本 `tests/ui-smoke.cjs` 使用 Playwright，可通过 `CINE_PLAYWRIGHT` 指向已有安装。脚本采用模拟接口，不能替代真实 Lab 联调。

## 2.0.5：修复流式接收误中断

原先将所有 SSE 协议字节累计到 16 MB 就报“内容过大”，包括已消费的 JSON 元数据、心跳和未保留的推理，可能在正文到来之前误断开。现在只限制实际保留内存：单条事件/未分隔行 1 MB、最终正文 2 MB、推理预览最近 8,000 字符；累计传输量只计数，不作为终止条件。正文预览同样仅保留最近 8,000 字符，完整正文仍需正常完成后才能作为报告保存。

分别展示正文与推理字符数、供应商返回的推理片段及正文预览，均用 textContent 渲染，不执行模型 HTML。不将推理写入报告或日志。调用增加 SiliconFlow 独立 thinking_budget=4096，max_tokens 仍用于正文；不设置总时间截止，不自动重发付费请求。依据官方 https://docs.siliconflow.cn/docs/api/chat-completions-post。

27 项单测、原生 Electron 取消/刷新/文件保留和双尺寸 UI 通过；覆盖超过 16 MB 协议流仍保存小正文，以及真正超大事件/正文拒绝。真实 GLM-5.3 合成 JSON 小样本约 5.2 秒返回 1,003 推理字符、30 正文字符、stop；没有重跑用户完整视频报告。不能以小样本代替长视频真实报告验收。

## 2.0.6：长图文报告分批生成

图文报告不再一次要求模型输出全部镜头。默认每批最多 6 条镜头证据，每次正文上限 8,192 token；输入按时间范围选择相关对白、场景和声音，保留所有镜头引用。确认 finish_reason=length 时，持久化更小的批次计划再分解处理，不原样重复请求；拆至一个镜头仍超限会明确停止，不无限重试。分批边界不视为新场景或剪切；跨批镜头不强行合并。

每批验证后立即写入账号/任务目录 `reports/<userId>/<jobId>/batches.json`。缓存绑定模型、完整证据及协议版本；取消、断线或重启后再次点击生成可复用完成部分。最后单独汇总全片概览并复核所有镜头恰好覆盖一次，才写完整 draft 并提首帧。概览失败不会丢失逐镜结果；概览输入异常过长时无损组装按时间段的概览，避免丢弃已完成内容。中断时已有 HTML 不变。

这是分批任务，不是无限增大模型输出窗口，也没有增加总生成时间截止。长报告会产生多次供应商调用，由用户硅基流动账户按实际用量结算。文字总结入口保持原有行为。

验收：34 项单测，包含 120 镜头/超过 100,000 字符的合成报告、批次超限递归拆分、断点恢复、模型或证据变更失效、取消与概览失败恢复；真实隔离 Electron 验证第 2 次请求失败后重载，只发剩余批次与概览，12 镜头首帧/HTML 导出成功；现有流式和双尺寸报告 UI 回归通过。没有重跑用户完整付费报告。
